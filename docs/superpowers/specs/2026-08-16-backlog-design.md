# Бэклог тайтлов — дизайн

Дата: 2026-08-16
Статус: одобрено пользователем, готово к планированию реализации

## Назначение

Локальная (позже — возможно, опубликованная в интернет) HTML-страница для ведения личного бэклога игр, сериалов, кино и аниме. Заменяет плоский Excel-список (`показываю даше мир.xlsx` на рабочем столе) визуальной галереей с фильтрами, сортировкой и карточками, в которые можно провалиться за подробностями. Новые тайтлы в будущем добавляются через Claude по запросу пользователя.

## Архитектура

Статический сайт без бэкенда и без сборки: обычные HTML/CSS/JS, открывается локально через `file://` и без изменений выкладывается позже на GitHub Pages/Vercel/Netlify.

```
backlog/
├── index.html
├── styles.css
├── app.js
├── data.js              # массив тайтлов, редактируется Claude при добавлении новых
├── images/covers/        # скачанные локально постеры (см. "Обложки")
└── README.md             # как пользоваться, как просить добавить тайтл
```

Данные держим в `data.js` (глобальная переменная `const TITLES = [...]`), а не в отдельном `.json` — чтобы страница читала их и через `file://` без CORS-ограничений на `fetch()`.

## Модель данных

```js
{
  id: "unique-slug",
  title: "Frieren: Beyond Journey's End",
  category: "game" | "series" | "movie" | "anime",
  status: "queue" | "in_progress" | "done",     // пользовательское, редактируется в UI
  airingStatus: "ongoing" | "completed" | null,  // только для series/anime; null для game/movie
  year: 2023,
  genres: ["драма", "фэнтези"],
  rating: 8 | null,        // личная оценка 1-10, пользовательское поле
  synopsis: "Короткое описание...",
  cover: "images/covers/frieren.jpg"
}
```

**Категоризация:** аниме — японская анимация (независимо от того, сериал это или полнометражный фильм). Прочая (западная) анимация распределяется по `movie`/`series` в зависимости от формата — многосерийная идёт в "сериалы", полнометражная в "кино". Отдельной категории "мультфильмы" нет.

**`airingStatus`** заполняется только для `category: series | anime`. Он не про статус просмотра пользователем, а про то, вышла ли франшиза полностью или ожидаются новые сезоны/части.

## Статус, оценка и удаление — редактирование прямо в UI

Пользователь меняет статус просмотра, личную оценку и может удалить тайтл прямо на странице, без обращения к Claude. Поскольку данные лежат в статичном `data.js`, эти изменения хранятся в `localStorage` в виде оверлея, накладываемого на базовые данные при рендере:

```js
// localStorage['backlog-overrides']
{ "frieren": { status: "in_progress", rating: 9 }, ... }
// localStorage['backlog-deleted']
["some-id", ...]
```

Добавление **новых** тайтлов по-прежнему делает Claude — правкой `data.js` и скачиванием обложки в `images/covers/`.

### Флаг "жду продолжения"

Вычисляется автоматически (не хранится отдельным полем): если `status === "done"` и `airingStatus === "ongoing"`, карточка и страница тайтла получают заметный бейдж (например, «⏳ Ждёт продолжения»), сигнализирующий, что пользователь досмотрел всё доступное на данный момент, но франшиза не закончена — нужно будет вернуться. Добавляется как отдельный пункт фильтра.

### Удаление

Кнопка удаления с подтверждением (destructive-действие → всегда через confirm-диалог) на карточке/странице тайтла. Удалённый id добавляется в `backlog-deleted` в `localStorage` и скрывается при рендере — сам `data.js` не трогается (что упрощает будущий git-diff при повторном добавлении Claude'ом новых тайтлов).

## Функциональность

- **Сетка карточек**: постер, название, бейдж категории, бейдж статуса, бейдж "жду продолжения" (когда применимо)
- **Разделы**: Все / Игры / Сериалы / Кино / Аниме (вкладки)
- **Фильтры**: категория, статус, жанр, "жду продолжения"
- **Поиск** по названию
- **Сортировка**: по названию, году, личной оценке, дате добавления
- **Счётчик прогресса** по каждому разделу (аналог "16/62" из экселя)
- **Страница тайтла** (модалка): крупный постер, синопсис, год, жанры, статус выхода, личная оценка, переключатель статуса просмотра, кнопка удаления

## Визуальный стиль

Тёмная киношная тема в духе Letterboxd/IGDB: тёмный фон, крупные постеры с hover-эффектом (подсветка/приподнимание), акцентный цвет для бейджей статуса, аккуратная современная типографика. Направление задаётся через `frontend-design`/`ui-ux-pro-max` на этапе реализации, чтобы избежать шаблонного вида.

## Обложки

При добавлении тайтла Claude ищет постер через веб-поиск и **скачивает его локально** в `images/covers/` (не хранит внешнюю ссылку) — чтобы картинки не пропадали и сайт работал офлайн и после переноса в интернет.
