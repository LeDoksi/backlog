# Лента: склейка событий одного друга за день (BL-112)

> Запрос Георгия 2026-10-15: активный друг за день начинает и завершает по несколько тайтлов, и лента состоит из него одного. Такие события нужно складывать в одну запись с несколькими обложками; тап открывает подробную панель с этими тайтлами, тап по тайтлу открывает его карточку.

**Решение.** Склейка на клиенте, без SQL: сервер уже отдаёт строки ленты (`feed`), клиент складывает строки одного человека одного вида (`started`, `completed`, `added`) за один календарный день (по часам телефона) в одну, начиная с двух. Разные виды остаются разными записями («начато 3 тайтла» и «завершено 2 тайтла»). Сезоны (`parts`) не склеиваются: это одна строка на тайтл в день, и она про сам тайтл. Так прод-базу трогать не нужно, а выкладка — обычный мерж.

Склеенная строка встаёт на место самого свежего события дня, время берётся у него же. Чтобы активный друг не выталкивал остальных из страницы, клиент просит у сервера 150 строк вместо 60 (сервер разрешает до 200).

**Панель.** Переиспользуется `FeedBatch` из волны 1 (панель «добавлено N тайтлов»): у неё появляется вид события. Заголовок «Лёша · завершено 3 тайтла», у завершённых в строке ещё «оценка 9/10», кнопка внизу ведёт на нужную полку друга («Завершено», «В процессе», «Хочет»).

## Шаги

- [x] `feedFormat.ts`: `collapseFeed(rows)` — склейка за день; `batchText(kind, count)` — «начато / завершено / добавлено N тайтлов»; `feedText` для склеенных строк; у `covers` допускается `null` (обложки нет — заглушка).
- [x] `socialStore.ts`: лента кладётся в стор уже склеенной; `social.ts`: `p_limit` 150.
- [x] `FeedItem.tsx`: ряд обложек и тап в панель для любой склеенной строки, не только добавлений.
- [x] `ui.ts` + `FeedBatch.tsx`: вид события в панели, заголовок, оценка, кнопка полки.
- [x] Тесты: `feedFormat.test.ts`, `feedBatch.test.tsx`, `socialStore.test.ts`, e2e `feed.spec.ts`.
- [x] Проверка в браузере: телефон 390px и десктоп, светлая и тёмная тема, сверка с дизайн-системой.

## Отклонения при реализации

- Значок с числом новых на вкладке «Друзья» считает сервер (`badge_count`), и он считает события, а не склеенные строки: у активного друга может быть «6» при двух новых строках. Чтобы считать строки, нужна правка SQL на проде; пока оставлено, если Георгий заметит и захочет — сделать отдельной правкой.
- Добавления (`added`) сервер уже складывал по часу; теперь клиент дополнительно складывает такие пачки за весь день. Добавление одного тайтла без обложки тоже попадает в список панели (по `title_id`).
