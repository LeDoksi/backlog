# «Что нового» в профиле: план реализации

**Карточка:** BL-116. **Спека:** `/mnt/project-files/review/2026-10-21-speka-chetyre-idei.md`, часть 1 (одобрена Георгием 2026-10-21). Разбор: `/mnt/project-files/review/2026-10-21-chetyre-idei-prozharka.md`, пункт 4.

**Goal:** люди видят, что нового в Бэклоге: строка «Что нового» в профиле, лист с записями, точка на вкладке «Профиль», пока не прочитано.

**Architecture:** тексты записей лежат в коде (`app/src/data/whatsNew.ts`), открываются без сети. База хранит только отметку `profiles.whats_new_seen_at` — дату самой новой записи, которую человек открыл. Точка горит, если самая новая запись новее отметки. Новые люди получают `now()` при регистрации (значение по умолчанию колонки), уже зарегистрированные — `null`, поэтому видят первую запись.

## Как добавить запись (для следующих тредов)

1. В `app/src/data/whatsNew.ts` добавить объект **в начало** `WHATS_NEW`: `{ date: 'ГГГГ-ММ-ДД', title, points: [...] }`. Дата — день выкладки. Одна запись в день: две с одной датой для точки считаются одной.
2. Показать текст Георгию в треде до выкладки. Только заметные вещи, простыми словами, без технических деталей; пишем от лица Георгия.
3. Больше ничего: ни SQL, ни правок интерфейса. После выкладки у всех, кто прочитал прошлые записи, загорится точка.

`tests/data/whatsNew.test.ts` проверяет порядок (новые сверху), формат даты и что даты не повторяются.

## Отклонения при реализации

- Бюджет JS был 249,9 КБ из 250. `@supabase/storage-js` и `@supabase/functions-js` (приложение их не использует) заменены заглушкой `app/src/lib/vendor/supabaseUnused.ts` через alias в `vite.config.ts`: стало 243,1 КБ, с «Что нового» 245,4 КБ. Вызов хранилища или функций теперь падает с понятной ошибкой.
- Тексты записей в TS, а не в JSON (как `data-info.json`): места в бюджете хватает, и точка считается без загрузки файла.
- Цвет точки — `--badge` (как счётчик у «Друзей»), а не акцент: в дизайн-системе уведомления этого цвета.
- Отметка — дата записи, а не время открытия: иначе запись, выложенная днём, считалась бы прочитанной теми, кто открывал лист утром.
- По просьбе Георгия в первую запись добавлен пункт про сам раздел «Что нового».
