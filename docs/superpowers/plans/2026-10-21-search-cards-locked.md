# Карточки из поиска без правки (BL-118): план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Лицо карточки из поиска никто не правит, она всегда как в источнике (старые ручные правки откатываются сами); ручную карточку правит только её автор.

**Architecture:** Клиент прячет «Редактировать» (`lib/release.isSearchCard`, автор из `titles.created_by`). База: триггер `titles_face_guard` отклоняет изменение полей лица (`42501 face_locked`) у карточки из поиска вне тихой записи обновления, а у ручной — от не-автора (кроме карточек без автора). Откат — тот же недельный проход BL-117 (`faceJob`), который после блокировки больше не бережёт «своё»: обложка и тексты всегда из источника (кроме «русское не заменять нерусским» и «машинный перевод не заменяет живой русский»), «Описание сезонов» очищается, руками собранный список сезонов пересобирается из источника с переносом галочек (`rebuildSeasons`, как в аудите BL-113). Ключ прохода меняется на `face:2:`, поэтому на каждой доске откат идёт при первом открытии. Снимок строк перед откатом делает продовый SQL.

**Spec:** `/mnt/project-files/review/2026-10-21-speka-chetyre-idei.md`, часть 3. После BL-117 (план `2026-10-21-release-badge-and-card-refresh.md`).

## Global Constraints

- Поля лица: title, original_title, cover, synopsis, year, genres, platforms, parts, parts_manual, season_info, category, source, source_id, release_date, digital_date.
- Личное остаётся: статус, галочки, оценка, «Скрыть от друзей», «Удалить».
- Ручная карточка без автора (`created_by is null`) — правит любой участник доски.
- Тексты в интерфейсе не добавляем: у карточки из поиска просто нет кнопки «Редактировать». Жалобы — в личку Георгию (кнопка позже, BL-E9).
- Категорию не трогаем при откате.

## Review Focus

1. Очередь правок без сети, созданная старой версией (правка названия карточки из поиска): сервер отвечает 42501, правка выбрасывается, очередь не застревает — тест `syncTitles` уже покрывает permanent; проверить pgTAP-кодом ошибки.
2. Тихая запись обновления (bl.quiet) карточки из поиска проходит; тихая запись не обходит запрет для чужой ручной карточки — pgTAP.
3. Удаление и смена статуса/оценки чужой ручной карточки на общей доске работают — pgTAP.
4. Повторное добавление после «Отменить» (upsert той же строки) не падает на триггере — pgTAP (одинаковые значения).
5. Пользовательская вертикальная обложка игры заменяется обложкой источника, но широкая шапка источника не заменяет вертикальную — тест `cardFixes`.

## Отклонения

- Отдельного одноразового прохода нет: недельное обновление BL-117 после блокировки само не бережёт «своё», а смена ключа на `face:2:` запускает его на каждой доске сразу. Машинный перевод по-прежнему не заменяет живой русский текст (это правило качества, а не «своё»).
- У карточки из поиска вместо «Редактировать» и меню «⋯» внизу две кнопки: «Скрыть от друзей» и «Удалить».
- Автор, удаливший аккаунт, оставляет карточку без автора (её может править любой участник доски).
